================================================================================
                    字符化头像 API 文档
================================================================================

本文档定义了字符化头像相关的所有接口，支持创建、查询、更新和删除 8x8、16x16、32x32 
三种大小的头像。头像由多个 RGBA 颜色字符串连接而成，格式为 #RRGGBBAA。

所有接口均需要有效的身份验证（JWT token）。


================================================================================
1. 创建新头像
================================================================================

请求方法: POST
请求路径: /api/avatar
身份验证: 需要

请求体 JSON:
{
    "avatar_size": 8,
    "avatar_data": "#eeccbba9,#eedd1199,#aabbccdd,#11223344,#99887766,#aabbccdd,#eeccbbaa,#ffddccbb,#eeccbba9,#eedd1199,#aabbccdd,#11223344,#99887766,#aabbccdd,#eeccbbaa,#ffddccbb,#eeccbba9,#eedd1199,#aabbccdd,#11223344,#99887766,#aabbccdd,#eeccbbaa,#ffddccbb,#eeccbba9,#eedd1199,#aabbccdd,#11223344,#99887766,#aabbccdd,#eeccbbaa,#ffddccbb,#eeccbba9,#eedd1199,#aabbccdd,#11223344,#99887766,#aabbccdd,#eeccbbaa,#ffddccbb,#eeccbba9,#eedd1199,#aabbccdd,#11223344,#99887766,#aabbccdd,#eeccbbaa,#ffddccbb,#eeccbba9,#eedd1199,#aabbccdd,#11223344,#99887766,#aabbccdd,#eeccbbaa,#ffddccbb,#eeccbba9,#eedd1199,#aabbccdd,#11223344",
    "is_current": true
}

参数说明:
- avatar_size (number, 必填): 头像大小
  有效值: 8, 16, 32
  8: 8x8 头像 (需要 64 个颜色)
  16: 16x16 头像 (需要 256 个颜色)
  32: 32x32 头像 (需要 1024 个颜色)
  
- avatar_data (string, 必填): 头像数据
  格式: 多个 #RRGGBBAA 颜色字符串，用逗号分隔
  示例: "#eeccbba9,#eedd1199,#aabbccdd,..."
  必须包含与 avatar_size 对应的正确数量的颜色
  
- is_current (boolean, 可选，默认 false): 是否设置为当前使用的头像
  如果为 true，会自动将同大小的其他头像设置为非当前


成功响应 (HTTP 200):
{
    "avatarId": 42,
    "message": "头像创建成功",
    "data": {
        "id": 42,
        "user_id": 5,
        "avatar_size": 8,
        "is_current": true,
        "created_at": "2024-03-20T14:30:45.123Z"
    }
}

失败响应 (HTTP 400):
{
    "error": "头像大小必须是 8、16 或 32 之一"
}
{
    "error": "8x8头像应包含64个颜色，但收到32个"
}
{
    "error": "无效的颜色格式: #ggbbaa，应为#RRGGBBAA格式"
}

说明:
- 每个头像大小最多保留多个版本，但同大小只有一个可被设置为当前使用
- 创建时如果 is_current=true，会自动清除同大小的其他当前使用标记


================================================================================
2. 获取用户所有头像
================================================================================

请求方法: GET
请求路径: /api/avatar
身份验证: 需要

查询参数: 无

成功响应 (HTTP 200):
{
    "message": "获取头像成功",
    "data": [
        {
            "id": 42,
            "user_id": 5,
            "avatar_size": 8,
            "avatar_data": "#eeccbba9,#eedd1199,#aabbccdd,...",
            "is_current": true,
            "created_at": "2024-03-20T14:30:45.123Z"
        },
        {
            "id": 41,
            "user_id": 5,
            "avatar_size": 16,
            "avatar_data": "#eeccbba9,#eedd1199,#aabbccdd,...",
            "is_current": false,
            "created_at": "2024-03-19T10:15:30.000Z"
        },
        {
            "id": 40,
            "user_id": 5,
            "avatar_size": 32,
            "avatar_data": "#eeccbba9,#eedd1199,#aabbccdd,...",
            "is_current": true,
            "created_at": "2024-03-18T09:20:15.000Z"
        }
    ]
}

说明:
- 返回按头像大小升序排列，同大小按创建时间降序排列
- avatar_data 包含完整的颜色字符串，可直接用于渲染


================================================================================
3. 获取指定大小的所有头像
================================================================================

请求方法: GET
请求路径: /api/avatar/size
身份验证: 需要

查询参数:
- size (integer, 必填): 头像大小，可选值 8, 16, 32

示例请求:
GET /api/avatar/size?size=8
GET /api/avatar/size?size=16

成功响应 (HTTP 200):
{
    "message": "获取头像成功",
    "data": [
        {
            "id": 42,
            "user_id": 5,
            "avatar_size": 8,
            "avatar_data": "#eeccbba9,#eedd1199,...",
            "is_current": true,
            "created_at": "2024-03-20T14:30:45.123Z"
        },
        {
            "id": 35,
            "user_id": 5,
            "avatar_size": 8,
            "avatar_data": "#aabbccdd,#11223344,...",
            "is_current": false,
            "created_at": "2024-03-15T12:00:00.000Z"
        }
    ]
}

失败响应 (HTTP 400):
{
    "error": "无效的头像大小参数"
}

说明:
- 返回指定大小的所有头像，按创建时间降序排列
- 通常用于让用户选择要使用的头像版本


================================================================================
4. 获取当前使用的头像
================================================================================

请求方法: GET
请求路径: /api/avatar/current
身份验证: 需要

查询参数:
- size (integer, 必填): 头像大小，可选值 8, 16, 32

示例请求:
GET /api/avatar/current?size=8
GET /api/avatar/current?size=32

成功响应 (HTTP 200):
{
    "message": "获取当前头像成功",
    "data": {
        "id": 42,
        "user_id": 5,
        "avatar_size": 8,
        "avatar_data": "#eeccbba9,#eedd1199,#aabbccdd,...",
        "is_current": true,
        "created_at": "2024-03-20T14:30:45.123Z"
    }
}

未设置头像响应 (HTTP 200):
{
    "message": "尚未设置8x8的头像",
    "data": null
}

失败响应 (HTTP 400):
{
    "error": "无效的头像大小参数"
}

说明:
- 返回用户当前正在使用的指定大小的头像
- 如果尚未设置，data 为 null，但返回码仍为 200
- 用于前端快速获取要显示的头像


================================================================================
5. 设置为当前使用的头像
================================================================================

请求方法: PUT
请求路径: /api/avatar/:avatarId/current
身份验证: 需要

URL 参数:
- avatarId: 头像ID，整数

请求体: 无 (或空对象 {})

示例请求:
PUT /api/avatar/42/current

成功响应 (HTTP 200):
{
    "message": "头像设置成功",
    "data": {
        "avatarId": 42,
        "avatarSize": 8,
        "isCurrent": true
    }
}

失败响应 (HTTP 400):
{
    "error": "头像不存在"
}

失败响应 (HTTP 403):
{
    "error": "头像不存在或无权删除"
}

说明:
- 自动将同大小的其他头像设置为非当前
- 只有用户自己的头像才能被设置为当前使用
- 同一大小最多只有一个头像的 is_current=true


================================================================================
6. 删除指定头像
================================================================================

请求方法: DELETE
请求路径: /api/avatar/:avatarId
身份验证: 需要

URL 参数:
- avatarId: 头像ID，整数

示例请求:
DELETE /api/avatar/42

成功响应 (HTTP 200):
{
    "message": "头像已删除"
}

失败响应 (HTTP 400):
{
    "error": "头像不存在或无权删除"
}

说明:
- 只能删除自己的头像
- 删除后不可恢复
- 如果删除的是当前使用的头像，需要重新设置其他头像为当前


================================================================================
7. 批量删除指定大小的所有头像
================================================================================

请求方法: DELETE
请求路径: /api/avatar/size
身份验证: 需要

查询参数:
- size (integer, 必填): 头像大小，可选值 8, 16, 32

示例请求:
DELETE /api/avatar/size?size=8

成功响应 (HTTP 200):
{
    "message": "已删除3个8x8的头像",
    "deletedCount": 3
}

失败响应 (HTTP 400):
{
    "error": "无效的头像大小参数"
}

说明:
- 删除指定大小的所有头像
- 返回实际删除的头像数量
- 如果删除的包括当前使用的头像，需要重新设置其他头像为当前


================================================================================
API 通用说明
================================================================================

身份验证:
- 所有接口都需要在请求头中提供有效的 JWT token
- 在 Authorization 头中放置 token: "Authorization: Bearer <your_token>"
- 若未提供或 token 无效，将返回 401 错误

用户隔离:
- 所有操作仅涉及当前登录用户的头像
- 无法查看、修改或删除其他用户的头像

颜色格式说明:
- 所有颜色使用 RGBA 格式: #RRGGBBAA
- RR, GG, BB, AA 均为两位十六进制数字 (00-FF)
- 例如: #FF0000FF 表示完全不透明的红色
- 例如: #00FF0080 表示半透明的绿色

像素数量规则:
- 8x8 头像: 64 个像素，需要 64 个颜色字符串
- 16x16 头像: 256 个像素，需要 256 个颜色字符串
- 32x32 头像: 1024 个像素，需要 1024 个颜色字符串

头像数据存储:
- 所有颜色按行主序（row-major order）排列
- 第一个颜色是左上角像素，最后一个颜色是右下角像素
- 例如 8x8 头像: [第1行8个颜色, 第2行8个颜色, ..., 第8行8个颜色]

当前使用标记:
- 每个用户的每个大小（8/16/32）最多只有一个头像的 is_current=true
- 当创建新头像或设置头像时，会自动更新此标记
- 前端应使用 /api/avatar/current?size=XX 端点快速获取要显示的头像

错误处理:
- 所有错误都会返回相应的 HTTP 状态码和错误信息
- 状态码 200: 请求成功
- 状态码 400: 请求参数错误
- 状态码 401: 身份验证失败
- 状态码 403: 权限不足
- 状态码 404: 资源不存在

================================================================================
API 端点汇总
================================================================================

POST   /api/avatar                    创建新头像
GET    /api/avatar                    获取用户所有头像
GET    /api/avatar/size               获取指定大小的所有头像
GET    /api/avatar/current            获取当前使用的头像
PUT    /api/avatar/:avatarId/current  设置为当前使用
DELETE /api/avatar/:avatarId          删除指定头像
DELETE /api/avatar/size               批量删除指定大小的所有头像
